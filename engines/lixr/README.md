# LiXR

**A fixed-point drum voice with feedback FM, a pitch envelope and a sample-rate decimator where the filter would be.**

Status: `tested` · Version: `3.0.0` · For: Model:Cycles OS 1.13 · License: MIT

## What it sounds like

One tableless oscillator runs from sine through triangle to saw and rectangle, with a noise and transient layer on top. Feedback FM roughens it, a pitch envelope gives the attack, and a sample-and-hold decimator takes the place of the filter, from clean to coarse and aliased. It is meant for drums and short percussion, but a long DECAY and a low RATE turn it into a bass or a texture. The voice is new code, in fixed point, in the spirit of the Sonic Potions LXR drum voices; no LXR code, table or sample is used.

## Knobs

| Knob | What it does |
|---|---|
| PITCH | the note, as on every machine; FINE detunes |
| COLOR | waveform: sine on the left, triangle in the centre, saw then rectangle on the right. Past 0.65 it adds noise, and past 0.85 a clap-like burst; SHAPE reduces the noise |
| SHAPE | feedback FM, from none to a quarter cycle of modulation, on a square law; the top of the range is the wild part |
| SWEEP | pitch envelope: depth (0 to 48 semitones) and decay time together |
| CONTOUR | labelled **Rate**: the decimator's sample rate, clean at 0 to a coarse, aliased buzz at 127 |
| DECAY | the stock amp envelope; GATE and PUNCH work as on Tone |

## Weight

CPU cost per voice: 6,335 to 6,499 instructions per block and per voice in the OS's own voice loop, against 6,572 for TONE (measured in emulation; not measured on the machine). It has no load governor of its own, so several LiXR tracks at once can starve the processor.

Works together with: other machine packages through a composer (model27 composes LiXR with SAMPLE, for example), and mods that do not add a machine.

Does not work with: the old *pre-built* single-machine tweaks (MACRO, ACID, the Syntakt engines, Model-TG's Sampler) — they take the same place in the firmware. Compose the packages instead.

A saved project stores which machine a track uses as a number, and that number depends on which machines were in the build. Set LiXR tracks back to a stock machine before flashing a build without LiXR.

## Install

Easiest: tick **LiXR** in the [model27 web flasher](https://100demons.github.io/cycles-flasher/flasher/) and bring your own official `model-cycles_OS1.13.syx`.

To build it yourself, this folder **is** a model27 package: copy it to `tools/machines/lixr/` in a tree that has `tools/compose.py` (the manifest points at `src/` and `addon/`), then compose it. `addon/36-lixr.json` is the ready-made single-machine tweak; `addon/lixr.o` is the compiled object the composer places. Sources build with `m68k-elf-gcc` using the flags in `manifest.json`; `src/lixr_tables.h` is generated by the engine's generator in model27.

This folder contains no Elektron firmware. Every write in the tweak is checked against the bytes of *your own* official OS file when it is applied.
