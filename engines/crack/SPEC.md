## 1. What CRACK is

A **hybrid-rate drum synth**. Its primary job: at the home position (all four knobs at 64) it plays one extremely
modern, impressive, record-ready snare. Its secondary job: every control is a **macro** that drives 6–11 internal
parameters at once, and each knob leaves the home snare in two directions, so the same engine also plays kicks, toms,
808/909 snares, claps, rimshots, brushes, gated 80s snares, metal hits, metallic hats, zaps, crushed lo-fi drums and
sustained tones.

Hard constraints:

- **CPU**: the worst-case block (§8) costs **no more than the stock TONE machine** measured in the same emulator run.
  Target ≤ 0.90 × TONE, to leave margin: the emulator counts instructions, not cycles.
- **Rates**: the core runs at **24 kHz** (16 samples per 32-frame block). The click and air layer runs at the full
  **48 kHz** (§4.4). Don't go below 24 kHz without the owner (§11).
- **Arithmetic**: integer C99 only. No float, no 64-bit arithmetic, no libc, no division in per-sample code (one
  division per block is fine), no EMAC inline assembly. This keeps the host build and the device build bit-identical.
  No signed overflow anywhere: phases are `uint32_t`, everything else is clamped.
- **Size**: code + tables ≤ 6 KB target (report the real number); tables ≤ 2 KB; variables ≤ 640 bytes per voice,
  comb buffer included (store the cached macro outputs as 16-bit). The chip has only 8 KB of instruction cache and 8 KB of data cache, shared with the OS and the
  other engines (Modded-Cycles `notes/26` and `notes/27`), so size is CPU.
- **Name**: `CRACK` (engine names are 5 letters or fewer). Package id `crack`.

## 2. Platform facts

- CPU: NXP MCF54415, ColdFire V4, ~250 MHz, no FPU. A load that misses the data cache costs tens of cycles
  (Modded-Cycles `notes/23`), so keep per-sample memory traffic to the voice's own state and its comb buffer.
- The voice-loop contract is documented in the header comment of `engines/refmachine/refmachine.c`:
  `crack_update(pmod, v, p)` then `crack_render(out, v)`, once per block of 32 frames at 48 kHz, per track. `pmod` is
  the trig's note in semitones `<< 16`; parameters are 8.8 words at `p + 0x14` (PITCH), `0x16` COLOR, `0x18` SHAPE,
  `0x1a` SWEEP, `0x1c` CONTOUR, `0x1e` PUNCH, `0x20` GATE, `0x22` FINE, `0x24` DECAY.
- **Copy the bridge pattern of `engines/punch/punch.c`** (the owner's percussion engine, already working on hardware):
  it reads velocity from `0x40fe4cdc` (a 16-bit word per track, velocity `<< 8`; **0 means "not set" → use 100**),
  PUNCH and GATE as on/off, the trig (`v + 0x38`), the note end (`v + 0x3c`), detects the first block after a machine
  change, and skips silent voices. Take the pitch maths from `refmachine.c` (`phase_inc`), rescaled for 24 kHz.
- CRACK makes its **own envelopes** and does not call the stock amp chain (`AMP_ENV` / `VCA` / `PUNCH`), as PUNCH
  does. It reads DECAY itself and uses it as a macro (§5.4).
- Output: `out[32]`, `int32_t`, Q31.
- CPU is measured with `tests/emu/mcengine.py` → `count_instructions()`: instructions per block, per voice. The
  default emulator trig is note 60 (`tests/emu/harness.py` → `play`).
- The OS's voice loop halves each track in place after `render` (Modded-Cycles `notes/36`). When you compare the
  emulator with the host, reproduce that halving exactly (arithmetic shift right by 1); never widen the tolerance.

## 3. Signal flow

```
 trig, velocity, note, 8 knobs, PUNCH, GATE
        │
        ▼
 MACRO MAPPER (per block; recomputed only when an input changes)  ──►  ~45 internal parameters
        │
 ┌──────┴─────────────────────────── 24 kHz core: 16 samples per block ───────────────────────────────┐
 │ BODY   3 sine modes (phase accumulators), freq = f0 × ratio_k × 2^(tension env + spike env)        │
 │        mode 2 phase-modulates mode 1                                                               │
 │ WIRES  noise ─► TPT state-variable filter (BP/HP mix) ─► × wire env × (1 − r + r·|mode 1|)         │
 │        + clap bursts (an envelope pattern on the same noise)                                       │
 │ RING   comb, ≤ 128 samples, tuned to f0 × ring ratio, damped and clamped feedback                  │
 │ HEAT   sum ─► transient boost ─► envelope compressor ─► drive ─► soft/hard clip, fold ─► tilt EQ   │
 │        ─► crush ─► DC blocker                                                                      │
 └──────┬─────────────────────────────────────────────────────────────────────────────────────────────┘
        ▼  2× upsample (4-point midpoint)
 48 kHz: noise ─► 1-pole highpass ─► × (click env + air env) ─► (+) ─► velocity/level ─► clamp ─► out[32] (Q31)
```

Why hybrid: a modern snare's weight lives below 8 kHz and its "expensive sheen" lives above 12 kHz. Running the body,
wires, ring and processing at 24 kHz halves their cost; the content above 12 kHz is mostly noise, which is cheap to
make at the full 48 kHz. That pairing is what lets CRACK be much richer than TONE for the same CPU.

## 4. The layers

### 4.1 Body (24 kHz)

- Three modes. Each is a `uint32_t` phase accumulator into a **parabolic sine** (as in `refmachine.c`, no table).
- Fundamental f0 = the trig's note + (PITCH − 64) + FINE, then a fixed **−5 semitone** transpose (`BODY_TRANSPOSE`),
  so the default trig (note 60, PITCH 64) gives **196 Hz (G3)**. Document it in the README.
- Mode k frequency = f0 × ratio_k × 2^((tension env + spike env) / 12). Both pitch envelopes are in semitones and decay
  exponentially to 0; they are computed per block, and each mode's phase increment is ramped linearly across the
  block's 16 samples.
- Each mode has its own exponential amplitude envelope (by default mode 2 decays in 0.6× and mode 3 in 0.4× of mode
  1's time).
- Phase modulation: mode 2's output × PM index is added to mode 1's phase.
- A mode above 10 kHz is muted for that block (Nyquist is 12 kHz at the core rate).
- On a trig from silence, phases start at 0. On a retrigger while sounding, phases continue (no click).

### 4.2 Wires (24 kHz)

- White noise (32-bit LCG) → **TPT ("zero-delay feedback") state-variable filter** (Zavalishin / Simper) → a mix of
  its bandpass and highpass outputs. `g = tan(π · fc / 24000)` comes from a small table; the other coefficients are
  computed per block (one division per block is fine). **Don't use the Chamberlin SVF**: it goes unstable above about
  fs/6 = 4 kHz at 24 kHz, and the wires live at 2–8 kHz. Clamp fc to 10 kHz.
- Wire envelope: a delay (0–3 ms: the wires answer a moment after the head), an attack, an exponential decay, and the
  gated shape above DECAY 100 (§5.4).
- **Rattle (head coupling)**: wire amplitude × (1 − r + r · |mode 1| normalised). The wires buzz at the head's pitch.
  This is the main realism trick; it is protected.
- **Clap**: an envelope pattern (1–4 short bursts 6–14 ms apart, then a tail that starts at the last burst) added to
  the wire envelope, on the same noise and filter.
- The filter's cutoff tracks pitch at half rate: +0.5 octave per octave of note/PITCH change.
- **Round robin**: on every trig, tiny seeded variations from the voice's own LCG: ±0.3 dB level, ±3 % wire cutoff,
  ±0.25 semitone tension depth, ±10 % click decay. It stops rolls sounding like a machine gun. It's deterministic, so
  host and emulator still match.

### 4.3 Ring (24 kHz)

- Comb filter on an `int16_t` buffer of 128 samples per voice. Delay = round(24000 / (f0 × ring ratio)); if that is
  over 128, halve it until it fits (one octave up each time).
- Feedback through a 1-pole lowpass (damping) and a clamp: it must stay stable at every setting and die away after the
  envelopes end.
- Input = (body + wires) × ring send; output × ring level into the sum.
- When the ring level is 0 and the buffer has decayed, skip it.

### 4.4 Click and air (48 kHz)

- One noise source → 1-pole highpass (cutoff from the macros, 1–8 kHz) → × (click env + air env), added after the
  upsampler.
- Click env: instant attack, 0.5–6 ms exponential decay, computed **per sample** (one multiply) because it is shorter
  than a block.
- Air env = wire env × air amount, so the air follows the wires, the clap bursts and the gated shape.
- This layer is what puts real content above 12 kHz. A hero check (§9.1) requires it. It is protected.

### 4.5 Heat: the processing chain (24 kHz)

- **Transient boost**: a short gain envelope (−3 to +7 dB, 3–8 ms) on the sum.
- **Envelope compressor**: per block, gain = 1 / (1 + k · E), where E is the current summed envelope level. CRACK
  knows its own envelopes, so it needs no level detector and no lookahead. Reciprocal from a small table, ramped per
  sample. This lifts the tail: the "parallel compression" sustain of a produced snare.
- **Drive → clip**: drive gain, then a soft cubic (y = x − x³/3 on the clamped range, two multiplies) that morphs to a
  hard knee; a wavefold above HEAT 104.
- **Tilt EQ**: one 1-pole lowpass split: y = x + t · (x − lowpass(x)). t > 0 brighter, t < 0 warmer.
- **Crush** above HEAT 104: sample-and-hold every 1–4 core samples (24 → 6 kHz) and bit masking (16 → 6 bits).
- **DC blocker**, always on.
- **Makeup gain** per HEAT breakpoint, tuned so the RMS of the first 150 ms stays within ±3 dB of the hero across
  HEAT 0–127.

### 4.6 Upsampler (24 → 48 kHz)

- 4-point midpoint: even output = x[n−1]; odd output = (9·(x[n−1] + x[n]) − (x[n−2] + x[n+1])) / 16, with shifts, not
  a division. One core-sample latency. Keep the last 3 core samples per voice.

### 4.7 Envelopes, retrigger, silence

- Every envelope is computed per block and ramped linearly per sample, except the click (per sample).
- Retrigger: envelopes restart their attack from their current value; filter, comb and phase states continue. No
  click.
- Silence: when every envelope is below −100 dB, the ring is skipped and no trig is pending, write zeros and skip all
  work (as `refmachine.c` and `punch.c` do), and reset the states for the next trig.

## 5. The controls

Knob values are read as in `refmachine.c` (`knob()`: 8.8 words → 0..32766) and used with their fractional part, so
macro moves and LFOs are smooth. Every macro is a **piecewise-linear table** with breakpoints at 0 / 32 / 64 / 96 / 127,
interpolated (frequencies and times in the log domain). The values below are starting points: tune them within ±30 %
to pass §9, and write the final values in the README.

### 5.1 Home = the hero snare

PITCH 64, COLOR 64, SHAPE 64, SWEEP 64, CONTOUR 64, DECAY 40, PUNCH off, GATE off, velocity 100, default trig. These
are the manifest defaults (`decay_default` 40), so a fresh track is the hero.

**Target sound**: a modern production snare, the kind that comes off a mixed pop / trap / EDM record already layered
and processed. A tight ~196 Hz body with a fast "crack" (pitch falls ~4 semitones in ~18 ms, on top of a 12-semitone,
4 ms snap tick); a crisp full-band click; dense, bright wires (2.5–8 kHz) that buzz with the head; real air above
12 kHz; a hint of clap at the onset for thickness; a faint ring at ~2.3× the fundamental; then a soft-clipped,
compressed "smack" with the tail lifted. About 250–300 ms. Loud and bright, never harsh, no mud below 100 Hz.

### 5.3 PITCH, PUNCH, GATE and velocity

- **PITCH**: sets f0 as in §4.1. The wire cutoff tracks at +0.5 octave per octave; the ring follows f0 exactly.
- **PUNCH (on/off, p-lockable) → "Rim"**: the stick hits the rim and the head together. Applied as deltas on top of
  whatever the macros give, so it works at every setting (on a tom it's a rim click, on a kick a beater click): ring
  level +0.25, ring feedback +0.1 (max 0.92), ring ratio × 1.25; click +6 dB and click highpass × 1.5; mode 3 level
  +0.3; spike +5 st; wire decay × 0.75; wire level × 0.85; overall +2 dB.
- **GATE (on/off)**: while the trig is held, mode 1 and the wire envelope stop decaying once they are 12 dB below their
  peak, and hold until the note ends; then they decay normally. This turns CRACK into a sustained tone or noise bed
  (a bass with SHAPE ≤ 20 and COLOR 0).
- **Velocity** (v = velocity / 127; 0 is read as 100, like PUNCH): level = 0.1 + 0.9·v²; click level × v²; wire
  cutoff × (0.6 + 0.4·v); spike depth × (0.5 + 0.5·v); rattle × (0.5 + 0.5·v). Soft hits are quieter and darker,
  accents crack. The hero's loudness is calibrated at velocity 100.

### 5.4 DECAY (the stock knob, read as a macro)

| DECAY | 0 | 20 | 40 (home) | 64 | 90 | 100 | 101–127 |
|---|---|---|---|---|---|---|---|
| body T60 | 25 ms | 80 ms | 180 ms | 350 ms | 900 ms | 1.4 s | as at 100 |
| wire T60 | 20 ms | 110 ms | 260 ms | 500 ms | 1.2 s | 2.0 s | gated shape |

Above 100 the wire, air and clap envelopes take a **gated shape**: attack, a flat hold that droops about 3 dB, then a
12 ms fade. The hold grows from 60 ms at 101 to 450 ms at 127. It's the 80s gated snare, without a reverb (the
Model:Cycles' own reverb does that job).

## 8. CPU budget

Rough estimate (instructions per block, per voice):

| part | per sample | samples per block | per block |
|---|---|---|---|
| body: 3 modes + PM | ~40 | 16 | ~640 |

**Worst case** = the trig block with everything active at once: COLOR 96, SHAPE 127, SWEEP 127, CONTOUR 127, PUNCH on,

1. crush (HEAT's top becomes a harder clip only)

6. mode 3 at half the update rate (every other core sample, held)

## 9. Checks

All on host renders at 48 kHz, note 60, velocity 100, home settings, unless stated. Onset = the first sample above
−60 dBFS. Q31 full scale = 0 dBFS. "Band energy" = the sum of |FFT|² in the band over the window (Hann).

### 9.1 Hero (all must pass)

1. **Level**: peak between −6 and −0.5 dBFS on the host. In the emulator, RMS of the first 150 ms within ±3 dB of
   stock SNARE (§9.4).
2. **Pitch**: the strongest peak between 120 and 400 Hz, 20–120 ms after onset, is at 180–215 Hz.
3. **Crack** (from `--trace`, not the audio): mode 1 is ≥ 3 semitones above f0 at the trig block and back within
   0.5 semitone of f0 by 30 ms.
4. **Balance** (0–150 ms): body band 150–400 Hz and wire band 2–8 kHz within ±6 dB of each other; air band 12–20 kHz
   no more than 24 dB below the wire band (proves the 48 kHz layer); 20–90 Hz at least 15 dB below the body band.
5. **Attack**: the peak of the first 3 ms is ≥ 0.7 × the overall peak.
6. **Length**: a 5 ms RMS envelope falls 40 dB below its peak 170–380 ms after onset.
7. **Smack**: RMS of 80–150 ms is no more than 22 dB below RMS of 0–30 ms (the lifted, compressed tail).
8. **Clean**: no jump between consecutive samples larger than full scale (no wraparound); |mean| over 0–300 ms below
   −50 dBFS; output exactly 0 within 50 blocks of every envelope reaching −100 dB.
9. **Retrigger**: trigs at 0 and 40 ms. The largest sample-to-sample step around the second trig is ≤ 1.2 × the
   largest at the first onset.
10. **Deterministic**: two renders of the same script are identical.

### 9.2 Macros (other controls at home; each macro at 0, 16, 32 … 112, 127)

- Every point: RMS (0–150 ms) above −40 dBFS, and 9.1 #8 passes.
- **COLOR**: the ratio of wire band (2–8 kHz) to body band (150–400 Hz) rises from 0 to 96 (one dip ≤ 1 dB allowed).
  At 127, the 1–4 kHz band's envelope shows ≥ 3 separate bursts in the first 40 ms.
- **SHAPE** (COLOR 0, body only): energy between 3 × f0 and 10 kHz is lowest at 0 and highest at 127; the tension
  drop (trace) shrinks from 0 to 127.
- **SWEEP**: energy(0–3 ms) / energy(3–30 ms) rises from 0 to 96; at 127 the trace shows mode 1 ≥ 2 octaves above f0
  at the trig block.
- **HEAT**: RMS (0–150 ms) within ±3 dB of the hero at every point; crest factor (0–150 ms) falls from 0 to 96; at
  127 the trace shows hold 4 and 6 bits.
- **DECAY**: the −40 dB time rises from 0 to 100; from 101 to 127 the trace shows the wire envelope holding, then
  fading in ≤ 15 ms.
- **PUNCH**: on vs off at home, energy above 3 kHz in the first 20 ms is ≥ 2 dB higher with PUNCH on.
- **Velocity**: 30 vs 127, RMS differs by ≥ 10 dB and the spectral centroid (0–50 ms) is higher at 127.
- **GATE**: DECAY 20 and a 300 ms note: RMS at 250 ms is ≥ 20 dB higher with GATE on than off.

### 9.3 Recipes (§5.5)

Each renders cleanly (9.1 #8) with RMS above −40 dBFS. Plus: Kick: strongest peak below 120 Hz. Clap: ≥ 3 bursts.
Metallic hat: ≥ 50 % of the 0–100 ms energy above 3 kHz. Zap: trace shows mode 1 ≥ 2 octaves above f0 at the trig
block. Sustained bass: the trace shows mode 1 within 0.1 semitone of f0 (49 Hz) while the
note is held, and the audio's strongest peak during the hold is below 60 Hz.

### 9.4 Emulator (device code): from M2 on, and after each M3 group

1. `tests/emu/test_engines.py --cycles <OS> --machines crack` passes (in M4 also with `feral9,punch,blast,crack`):
   CRACK dispatches and sounds, the six stock machines are unchanged.
2. **Sample-exact**: the emulator's CRACK output equals the host render sample for sample (after the OS's halving,
   §2) for: the hero, the rimshot, the ghost note (write the 16-bit word velocity `<< 8` at `0x40fe4cdc + 2 × track` in
   emulator memory before the trig block, as PUNCH reads it), a retrigger at 40 ms, every recipe from M4 on, and a machine change mid-note. Compare emulator

3. **CPU**: worst case, steady and silent blocks vs TONE, measured in the same run (§8).

5. **Six voices**: six tracks of CRACK at worst case cost no more than six tracks of TONE.
